# Управление 0.1.0-alpha

Белые W1–W16 и чёрные B1–B11 считаются слева направо на 27-клавишной панели FM‑1, от F3 до G5. Чёрные эффекты действуют, пока клавиша удерживается. Несколько эффектов можно сочетать; дробь с наибольшим делением имеет приоритет.

| Белая | Действие |
|---|---|
| W1–W7 | Two Step, Amen Style, Think Style, Funky Ghost, Apache Style, Roller, Halftime |
| W8 | Следующий seed вариации |
| W9 / W10 / W11 | Ghost-сбивка на 1 / 2 / 4 доли |
| W12 | Ghost-сбивка на такт; отдельного Amen fill-алгоритма пока нет |
| W13 | Дополнительные kick + hat |
| W14 / W15 | Убрать / вернуть барабаны; саб продолжает играть |
| W16 | RETURN: восстановить сохранённую сцену и снять эффекты |

| Чёрная | Удерживать |
|---|---|
| B1 / B2 / B3 | Snare roll 1/16 / 1/32 / 1/64 |
| B4 | Ghost rush на нечётных шагах |
| B5 | Reverse предыдущего такта |
| B6 | Предыдущий такт с половинной скоростью |
| B7 | Короткий gate в начале каждого шага |
| B8 | Pitch down на октаву, через половинную скорость PCM |
| B9 | Посыл в dub delay: dotted eighth, фильтр и feedback; хвост остаётся после отпускания |
| B10 | High-pass throw |
| B11 | Моментальный drum kill, саб остаётся |

PCM готов после первого полного такта. B5/B6/B8 автоматически выводят его на передний план. B6 и B8 в alpha дают одинаковое замедление; вместе — четверть скорости. Pitch down пока не сохраняет длительность. Mix по умолчанию 0: слышен живой синтез.

| Панель FM‑1 | Действие |
|---|---|
| PLAY | Старт / стоп; новый старт начинает фразу заново |
| SELECT encoder | Темп 140–190 BPM |
| ALGORITHM encoder | DNB / Jungle / Liquid |
| PRESETS encoder | Выбрать одну из 8 сцен; применение на границе такта, либо при следующем старте |
| KNOB1–4 | Complexity / Roll / Crunch / Print Mix |
| SEL | Переключить LIVE / DRUM KEYS |
| HOME | Вернуться в LIVE |
| OCT+ / OCT− | Новая вариация / RETURN |
| SEQ | Однотактовая ghost-сбивка |
| ARP | Саб вкл./выкл. |
| EDIT | Следующий kit |
| SAVE | Запрос сохранения; исполнится после STOP и четырёх полностью тихих аудиоблоков |

В DRUM KEYS клавиши запускают восемь голосов циклически, отдельно для белого и чёрного ряда. Это режим прослушивания, velocity физических клавиш фиксирована. FX/ENV/LFO/GLO/REC в alpha не назначены. Выбор тоники саба пока доступен через web-интерфейс.

RETURN возвращает настройки последней применённой сцены либо последнего SAVE (после включения — сохранённые из flash). Пока SAVE не выполнен, движение ручек не меняет эту точку возврата.

## USB MIDI

Канал 10: GM drums с velocity. 35/36 kick; 38/40 snare; 39 ghost; 42/44 closed hat; 46 open hat; 49/51/57 ride; 41/43/45/47/48/50 tom; 37/54/56 percussion.

На остальных каналах номера нот **36–51** вызывают W1–W16, **60–70** удерживают B1–B11. Номера точнее названий октав, которые различаются между программами. Note Off/velocity 0 снимают эффект только своего канала. CC20–23 управляют четырьмя макросами на FM‑1; CC120/123 — PANIC. Браузер поддерживает ноты, transport и PANIC; CC20–23 пока только прошивка.

MIDI Start / Continue / Stop принимаются. Подстройка BPM по MIDI Clock **не включена**. TRS MIDI в этой сборке отключён. MIDI out отсутствует.

## Браузер

Q W E R T Y U I O P [ удерживают B1–B11. SPACE — transport, ESC — RETURN, когда фокус вне полей и кнопок. Экранные клавиши доступны мышью, касанием и через Tab + Space/Enter. Потеря фокуса/скрытие окна снимает удержания. MIDI IN требует разрешение браузера. REC WAV сохраняет stereo PCM16 с частотой AudioContext, максимум 60 секунд.
