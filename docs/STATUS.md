## Исправлено после независимого review

- Раздельное владение удержаниями для панели и MIDI-каналов; drum channel не освобождает чужие эффекты.
- Pitch down действительно меняет скорость PCM.
- Новый старт сбрасывает fill/mute/roll/print cursor; ручные барабаны слышны при остановке.
- SAVE ждёт полностью тихие блоки, а не только нулевую master envelope.
- Сбивка действует в начале такта; kill имеет приоритет над эффектами и room.
- Саб дотухает до точного нуля; peak meter не застревает.
- Keyboard release использует `event.code`, сохраняя работу при Shift; номер сцены восстанавливается из flash.
- Dub throw имеет отдельный ограниченный tempo delay и хвост; PANIC очищает его.
- Installer распознаёт собственный loader `9174XYZ` при возобновлении обновления, сохраняя запрет на неизвестные loaders.

## Не проверено

Физический FM‑1: загрузка CPU и запас audio ISR, аудио underruns, LCD/LED, энкодеры, USB MIDI, реальная запись flash, USB-установка, прерывание обновления и recovery. Физические входы проверены по API унаследованной платформы и target-сборкой. Браузерный UI не прошёл визуальную и интерактивную проверку в реальном браузере; AudioWorklet проверен отдельно в Node.

Первый аппаратный тест должен подтвердить стабильный звук без эффектов, затем roll/reverse/dub в сочетании, STOP/SAVE, USB MIDI и безопасный возврат к рабочей прошивке. Только после измерения худшего времени ISR стоит наращивать DSP.

## Следующий этап архитектуры

- Семантическая нарезка синтезированного print: сейчас воспроизводится целый предыдущий такт, без маркеров ударов и перестановки slices.
- Crossfade на границах PCM, независимое pitch/time и более точная акустическая модель snare/ride. Смена print на границе такта может щёлкать; акустическая настройка ещё впереди.
- Более разные Liquid/Jungle-профили, отдельные Amen-fill grammar, грув-шаблоны и расширенная вариативность. W11/W12 сейчас одинаковые однотактовые ghost fills; B6/B8 одинаково замедляют PCM.
- External MIDI Clock tempo sync, TRS MIDI, полноценный PANIC с физической панели, выбор тоники на устройстве, MIDI out.
- Аппаратная квалификация, подписанные GitHub Releases и включение в Firmware Hub. Эта alpha не добавлена в каталог автоматически.
